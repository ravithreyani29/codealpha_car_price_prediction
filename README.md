# Car Price Prediction with Machine Learning

This project predicts car prices using a Random Forest Regression model. It includes data preprocessing, feature encoding, model training, prediction, and evaluation.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

## Features
- Data preprocessing
- Label encoding
- Random Forest Regression
- Model evaluation using Mean Absolute Error (MAE)
- Feature importance visualization
